# Decision Tree Classifier - Machine Learning Project

This repository contains a Jupyter Notebook that demonstrates the implementation of a Decision Tree Classifier using Python and popular data science libraries.

##  Project Files

- `DT.ipynb` - The main Jupyter Notebook that contains the data preprocessing, model training, evaluation, and visualization steps.

##  Key Features

- Data loading and preprocessing
- Training a Decision Tree Classifier
- Visualizing decision boundaries or tree structure
- Model evaluation (accuracy, confusion matrix, etc.)
- Use of libraries like `pandas`, `numpy`, `sklearn`
